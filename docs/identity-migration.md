# Identity and naming

The product and repository are **deckystream**, in
[`egohygiene/deckystream`](https://github.com/egohygiene/deckystream). The fresh
repository is independent; the original project and its attribution/history
remain preserved. The owner has now authorized the active CLI, module, plugin,
package and default namespace rename.

Read [product naming and upgrades](product-naming.md) for the exact primary
identities and legacy handoff. A name change must not lose keys/media, split the
control lock, silently change capture or create two controlling backends. New
source and artifacts need new qualification before the shared Deck session.

## Selected brand

The owner selected lowercase **deckystream** and **01 / aurora**. The existing
vector/raster sources and exports are used in the README and compact UI.
[Open the brand kit](../branding/aurora/README.md) and
[the selected-source review](selected-aurora.md). Earlier concepts remain
concepts; their original source names are historical facts.

The current metadata is in `product.json` and `.identity/identity.json`. Original
creator/provenance records continue to identify where the assets were made. The
rename does not rewrite those records or fill empty approval arrays. Final
artwork rights/license, publisher, production adoption and actual Deck rendering
remain explicit owner/evidence gates under
[finalization #1](https://github.com/egohygiene/deckystream/issues/1).

## Identity tooling

The consumer lock is [`.identity/toolchain.lock.json`](../.identity/toolchain.lock.json).
It pins an immutable additive source implementation and a hash-verified
validator; it is not a claim that the complete current contract shipped in
published Identity v1.0.0. The local aurora generator remains a draft-kit
preparer, rather than the production Identity compiler. See the
[brand adoption packet](migration-brand-packet.md) for retained source, rights
and release-tooling facts. No Identity repository changes are part of this rename.

This is an independent community project, with no claimed endorsement from
Valve, Decky or OBS. Name/mark availability and publication approval remain
separate from choosing the working name.
